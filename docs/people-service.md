## 👥 3. People Service — User API (Методы управления профилем пользователя)

Эндпоинты для заполнения, обновления и просмотра персональных данных клиентов банка. Все запросы идут через API Gateway на порту `8080`, который автоматически прокидывает UUID пользователя в заголовке `X-User-Id`.

---

### 1) Ввести личные данные (Add User Data)
Позволяет пользователю привязать свои персональные и паспортные данные к аккаунту после первой регистрации.

* **Метод:** `POST`
* **Путь через Gateway:** `http://localhost:8080/users/addData`
* **Заголовки (Headers):**
  * `X-User-Id: <UUID>` (Идентификатор пользователя, автоматически прокидываемый шлюзом Gateway)
* **Тело запроса (`AddUserDataDto` JSON):**
  ```json
  {
    "firstName": "Иван",
    "overageName": "Иванович",
    "lastName": "Иванов",
    "phone": "+79991112233",
    "passportNumber": "123456",
    "passportSerial": "4520",
    "gender": "MALE",
    "dateOfBirth": "1995-05-15"
  }
  ```
* **Успешный ответ (`200 OK : Added data successfully`):**
   
### 2) Просмотр данных пользователя (View User Data)
Возвращает детальную персональную информацию о текущем пользователе на основе его уникального идентификатора.

* **Метод:** `POST`
* **Путь через Gateway:** `http://localhost:8080/users/view/data`
* **Заголовки (Headers):**
  * `X-User-Id: <UUID>` (Идентификатор пользователя, автоматически прокидываемый шлюзом Gateway)
* **Тело запроса:** отсутствует
* **Успешный ответ (`200 OK — ViewDataUser`):**
  ```json
  {
    "firstName": "Иван",
    "overageName": "Иванович",
    "lastName": "Иванов",
    "phone": "+79991112233",
    "passportNumber": "123456",
    "passportSerial": "4520",
    "gender": "MALE",
    "dateOfBirth": "1995-05-15",
    "registrationDate": "2026-06-07T15:00:00"
  }
  ```
* **Успешный ответ (`200 OK : Added data successfully`):**

### 3) Просмотр данных пользователя (View User Data)
Возвращает детальную персональную информацию о текущем пользователе на основе его уникального идентификатора.

* **Метод:** `POST`
* **Путь через Gateway:** `http://localhost:8080/users/view/data`
* **Заголовки (Headers):**
  * `X-User-Id: <UUID>` (Идентификатор пользователя, автоматически прокидываемый шлюзом Gateway)
* **Тело запроса:** отсутствует
* **Успешный ответ (`200 OK — ViewDataUser`):**

  ```json
  {

    "firstName": "Иван",
    "overageName": "Иванович",

  }
  ```
